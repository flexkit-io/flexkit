# Contributing

Coding agents now write most of the code in open source, including this repo.

Because of that, we prefer `feature` PRs as human-written text rather than generated implementations. Keep it informal — the same way you would run an idea by a coworker. If we are aligned on the change, we're happy to burn our tokens on the underlying implementation.

Please do not have an AI expand what you would like to do into a formal proposal.

Submit the change as a PR that adds a `.txt` or `.md` file to the [`adrs/`](./adrs/) folder.

For bugs, open an issue. We appreciate that a lot, and will credit you as co-author on the commit if we merge a fix.

Report security vulnerabilities privately — see [`SECURITY.md`](./SECURITY.md), not a public issue.

Please follow our [Code of Conduct](./CODE_OF_CONDUCT.md) in all interactions with the project.
