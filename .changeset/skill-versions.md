Skills: every member keeps personal skills, while owners and developers also manage project and space skills. A skill can load **Always**, as part of every chat and run that can see it, for short rules such as tone or format; the list marks such skills. **History** on a Studio skill lists its saved versions, shows each one, and restores an earlier one as a new version. A skill proposal's review card shows its load mode. Older platforms that send no load mode or versions change nothing: skills load when relevant and the history says it is not available.
